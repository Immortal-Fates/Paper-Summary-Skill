# paper-summary

`paper-summary` 是一个 Codex Skill，用于把论文整理成简洁、面向复盘的中文 Markdown 笔记。它先理解论文的问题、核心框架和机制，再组织图表、公式、实验证据和批判性分析；第三方摘要只用于辅助定位，论文本身始终是事实依据。

## 安装与识别

将本目录放在 Codex 的用户级技能目录下：

```text
${CODEX_HOME:-~/.codex}/skills/paper-summary/
```

其中至少应包含 `SKILL.md`。Codex 会在可用的技能列表中识别它；若未立即出现，重启 Codex 会话。

## 使用方法

在包含论文链接的 Markdown 笔记中明确要求使用本技能，例如：

```text
使用 $paper-summary 总结当前笔记中的论文。
```

也可以指定论文链接和输出文件：

```text
使用 $paper-summary 总结 https://arxiv.org/abs/...，
并写入 papers/example.md。
```

如果只提供论文链接、没有说明要写入的位置，Codex 应先确认目标笔记或输出方式。

## 输入要求

- 一个可从出版社、DOI、OpenReview、arXiv、会议论文集或其他可靠来源访问的论文链接。
- 明确的目标笔记，或明确要求新建笔记及其路径。
- 如论文或目标目录已有固定格式，应同时提供该笔记或目录作为格式依据。

可访问的 PDF、HTML 或源文件有助于提取正文、公式、图表和引用信息。若论文页面无法访问，技能会优先尝试同一论文的官方或可靠替代来源。

## 输出内容

默认生成中文为主、技术名词保留英文的 Typora 友好 Markdown，主要包含：

1. `Takeaway`：仅使用英文，概括核心方法或贡献。
2. `Motivation`：研究问题、现有路线为何不足，以及论文目标。
3. `Core Mechanism`：先讲核心框架，再讲支撑机制、公式和对应图表。
4. `Experiment`：关键实验、主要结论，以及能支撑论点的表格或图片。
5. `Pipeline`：Mermaid 端到端流程图。
6. `Critical Thinking`：优势、具体失效条件、权衡、实验支撑和后续方向。

笔记还会包含经过核验的论文元数据和引用数；无法核验引用数时，会明确标记 `(Citations __unknown__)`。论文中的图片会按需保存为本地资源，并在对应解释下方引用。

## 注意事项

- 这不是独立的论文抓取或 Markdown 生成命令，而是供 Codex 遵循的阅读与写作流程。
- 自动总结仍可能遗漏或误读论文细节，提交前应检查原文链接、公式、图表和实验结论。
- 技能应优先遵循目标仓库现有格式，不应为套用默认模板而重写无关内容。

更多规则以 [SKILL.md](SKILL.md) 为准。
